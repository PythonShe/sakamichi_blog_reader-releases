## 소개

**사카미치 블로그**는 사카미치 시리즈 3개 그룹의 공식 블로그를 무료로 읽을 수 있는 팬메이드 앱입니다.

- **노기자카46** (乃木坂46)
- **사쿠라자카46** (櫻坂46)
- **히나타자카46** (日向坂46)

최신 블로그 글을 확인하고, 좋아하는 멤버를 찾고, 마음에 드는 글을 저장하세요 — 하나의 앱으로 모두 가능합니다.

## 주요 기능

- **블로그 피드** — 최신 블로그 글을 카드 레이아웃으로 탐색. 당겨서 새로고침, 스크롤하여 더 불러오기.
- **멤버 프로필** — 생년월일, 기수, 출신지, 혈액형, 별자리, SNS 링크 등 멤버 상세 정보 확인.
- **오시 (최애 멤버)** — 멤버 카드를 길게 눌러 "오시"로 설정. 오시 멤버는 전용 섹션에서 빠르게 접근 가능.
- **북마크** — 다시 읽고 싶은 블로그 글을 저장. 북마크한 글은 한 페이지에서 모아보기.
- **멤버 검색** — 이름으로 실시간 멤버 검색.
- **그룹 전환** — 노기자카46, 사쿠라자카46, 히나타자카46 간 원터치 전환.
- **다운로드 및 내보내기** — 블로그 콘텐츠를 기기에 저장. 캐시된 글을 이미지 포함 HTML 파일로 내보내기.
- **다크 모드** — 라이트, 다크, 시스템 기본 테마 완벽 지원.
- **다국어 지원** — 한국어, 영어, 일본어, 중국어 간체, 중국어 번체 지원.

## 개인정보 보호

사카미치 블로그는 **로컬 우선** 설계입니다. 열람 기록, 북마크, 설정 등 모든 데이터는 사용자의 기기에만 저장됩니다. 개인정보를 외부 서버에 수집, 저장, 전송하지 않습니다. 블로그 콘텐츠는 웹 브라우저와 동일하게 공식 사이트에 직접 접속하여 가져옵니다.

## 면책 조항

본 앱은 팬이 제작한 비공식 프로젝트입니다. 노기자카46, 사쿠라자카46, 히나타자카46 및 소속 기획사와는 **일체 관련이 없습니다**. 표시되는 블로그 콘텐츠의 저작권은 각 권리자에게 있습니다.
