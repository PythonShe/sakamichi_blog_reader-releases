## 简介

**坂道博客**是一款免费的粉丝自制应用，支持阅读坂道系列三个偶像团体的官方博客：

- **乃木坂46**
- **櫻坂46**
- **日向坂46**

浏览最新博客、发现喜欢的成员、收藏心仪的文章——一个应用全部搞定。

## 功能特色

- **博客动态** — 以卡片布局浏览最新博客文章。下拉刷新，上滑加载更多。
- **成员资料** — 查看成员详细信息，包括生日、期别、出生地、血型、星座、社交媒体链接等。
- **推成员** — 长按成员卡片即可设为"推"。推成员会显示在专属区域，方便快速访问。
- **收藏夹** — 保存想再次阅读的博客文章。所有收藏文章集中展示在一个页面。
- **搜索** — 输入名字即时搜索成员。
- **团体切换** — 在乃木坂46、櫻坂46、日向坂46 之间一键切换。
- **下载与导出** — 将博客内容保存到设备。可将缓存的文章导出为带图片的 HTML 文件。
- **深色模式** — 完整支持浅色、深色和跟随系统三种主题。
- **多语言** — 支持简体中文、繁体中文、英语、日语、韩语。

## 隐私保护

坂道博客采用**本地优先**设计。浏览记录、收藏、设置等所有数据仅保存在您的设备上。应用不会向外部服务器收集、存储或发送任何个人信息。获取博客内容时，应用直接访问官方网站，与使用浏览器访问无异。
