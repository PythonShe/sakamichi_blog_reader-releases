## 簡介

**坂道部落格**是一款免費的粉絲自製應用程式，可閱讀坂道系列三個偶像團體的官方部落格：

- **乃木坂46**
- **櫻坂46**
- **日向坂46**

瀏覽最新文章、發現喜歡的成員、收藏心儀的貼文——一個 App 全部搞定。

## 功能特色

- **部落格動態** — 以卡片佈局瀏覽最新部落格文章。下拉重新整理，上滑載入更多。
- **成員資料** — 查看成員詳細資訊，包括生日、期別、出生地、血型、星座、社群媒體連結等。
- **推成員** — 長按成員卡片即可設為「推」。推成員會顯示在專屬區塊，方便快速存取。
- **書籤** — 儲存想再次閱讀的部落格文章。所有書籤文章集中顯示在同一頁面。
- **搜尋** — 輸入姓名即時搜尋成員。
- **團體切換** — 在乃木坂46、櫻坂46、日向坂46 之間一鍵切換。
- **下載與匯出** — 將部落格內容儲存至裝置。可將快取的文章匯出為含圖片的 HTML 檔案。
- **深色模式** — 完整支援淺色、深色及跟隨系統三種佈景主題。
- **多語言** — 支援繁體中文、簡體中文、英語、日語、韓語。
